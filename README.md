# CURVE — Agency Website

Single-page bilingual (English / Arabic) website for **CURVE**, a full-service creative agency in Jeddah.

## Files

- `index.html` — the page: header, hero, profile, capabilities, selected work, market band, clients, contact, footer
- `styles.css` — the design system: light ground `#EDEDED`, black type, one identical treatment for every card, hover limited to a lift
- `script.js` — language switching (EN/AR + RTL), portfolio filters, lightbox, enquiry form
- `assets/` — logo marks, the client wall, selected-work photography, brand typeface (Riyad Bank, woff2)

## Run locally

Open `index.html` directly, or serve the folder:

```bash
python -m http.server 8080
```
